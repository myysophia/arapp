# 04 数据源策略（中国首发）

## 1. 目标与成功标准
- 目标：建立主数据源+备用数据源策略，确保中国首发可达与稳定。
- 成功标准：7 天探测下可达率 >= 99%，关键字段完整率 >= 95%。

## 2. 范围与非范围
- 范围：风险指数、分项指数、更新时间、来源说明。
- 非范围：真实监测站合作接入（本期仅模型点）。

## 3. 输入/输出与接口
- 输入：上游数据源返回的指数与预报。
- 输出：标准化字段 `risk_overall/tree_level/grass_level/weed_level/confidence`。
- 输出接口：供 `06` 的 `summary/forecast` 使用。

## 4. 数据模型与约束
- 标准化等级：`0-5`。
- 标准化来源：`source`（model/station/vendor）。
- 统一时效字段：`updated_at`、`expires_at`。

## 5. 异常与降级
- 主源超时：读取 `pollen_daily_cache`。
- 主源不可达：切备用源并记录 `provider_switch_event`。
- 双源都失败：返回最近有效数据 + 数据延迟提示。

## 6. 安全与合规
- 严格遵守数据许可，不输出超授权字段。
- 对外文案明确“模型推断，不是实时采样”。

## 7. 埋点与可观测性
- `provider_latency_ms`、`provider_error_rate`、`provider_switch_count`。
- 指标按源分桶监控，形成周报。

## 8. 测试与验收
- 上游模拟超时、空数据、字段缺失。
- 验证标准化映射一致性。
- 验证降级时客户端展示逻辑正确。

## 9. 依赖与里程碑
- 依赖：数据源准入评估、缓存表与 API 契约。
- 里程碑：第 3 周完成主源准入；第 6 周完成备用源演练。

## 10. 假设与默认值
- 首版默认来源类型 `model`。
- `confidence` 默认范围 `0.00-1.00`。
